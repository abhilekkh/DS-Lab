## 🚀 Getting Started

### Prerequisites

Install a C compiler such as GCC. On Windows, you can use MinGW-w64 or MSYS2.

### Compile and Run

Navigate to the directory containing the desired source file and execute:

```bash
gcc filename.c -o program
./program
```

On Windows, run the compiled executable using:

```bash
./program.exe
```

Replace `filename.c` with the name of the C source file you want to execute.
